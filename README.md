# 🛒 Superstore Sales Analysis

A data analysis project exploring sales trends, category performance, 
regional profitability, and top products using Python.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

## Key Insights
- Sales peak in November and December
- Technology is the highest revenue category
- The West region generates the most profit
- Some high-sales products have low profit margins

## Files
- `superstore_analysis.ipynb` — Main analysis notebook
- `superstore.csv` — Dataset used
